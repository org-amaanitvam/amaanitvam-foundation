# Amaanitvam Admin Portal

Administrative portal for managing Amaanitvam Foundation operations.

## Features

- Candidate management
- Member management
- Donations
- Learning Hub
- Contact inquiries
- Certificate management
- Website CMS
- Role-based authentication

## Tech Stack

- React
- Vite
- Firebase Authentication
- Tailwind CSS
- Amaanitvam Node.js backend APIs

## Local Setup

```bash
npm install
npm run dev
